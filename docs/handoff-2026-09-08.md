## 1. Domain model — read this first (it caused real confusion this session)

- Hierarchy: **group (N empresas/RUTs) → cuenta/account → expediente**. An **account** is a
  `case_file(kind=account)` = **1 empresa/contratante × 1 ramo × 1 vigencia**.
  - **Viña Santa Alicia is NOT a group** — it is an *account* (empresa) inside GRUPO VIÑA INDOMITA,
    which holds two RUTs: Viña Indómita SpA (99.568.600-7, case 6) and Viña Santa Alicia SpA
    (96.688.830-K, case 4). A group has NO RUT of its own; its empresas do.
- **Line = the ramo's schema, broker-defined, assigned per account; it defines the AI extraction.**
  Distinguish three things:
  - **Ramo** = `insurance_line` (global category: Incendio, RC…). Every account already has one.
  - **Line** = `line_record_schema` (the antecedentes schema for that ramo). Broker-owned; assigned
    to an account (`case_file.line_record_schema_id`) or resolved from the ramo as a fallback.
  - **Processed** = the extraction actually ran and a human validated. **Assigned ≠ processed.**
    (Case 6 is assigned a line but unprocessed → its mandatory fields, incl. RUT, are empty → the
    "Descargar Bases Técnicas" button is disabled with a "missing: Razón social, RUT, Desde, Hasta"
    reason. That is the completeness gate, not a RUT/tenancy problem.)
- **"Bases Técnicas" = the completed antecedentes rendered to the branded PDF — there is NO middle
  step.** The expediente view IS the bases-técnicas builder; "Descargar Bases Técnicas" is gated on
  completeness (`GET /pdf` returns 409 when incomplete).

## 2. Architecture principles established this session (binding)

1. **AI extracts categorized fields → human validates → CODE computes & assembles the document.**
   Any **derived/aggregate value (totals, sums) is computed by code, never AI-extracted.** The
   `monto total asegurado` is now `_matrix_grand_total(...)` (sum of the materias matrix), removed
   from `required_fields`, applied in `_antecedentes_read` and the PDF endpoint. (User correction;
   the earlier AI-extracted total disagreed with the code-summed table.)
2. **Known account data should be code-prefilled, not AI-extracted** — see backlog #1 (insured
   RUT/razón social from the contratante client; vigencia from the account period). Not done yet.
3. **PDF branding:** cover = Radal logo lockup (isotype `radal-mark-teal.svg` + "Radal." in Space
   Grotesk). Content-page running header = **broker LEFT** (uploaded logo, else the broker name in a
   personalised display font — never a monogram) + **Radal isotype RIGHT**. Footer = broker legal
   name + page n/N. Only Ossa (broker 1) has a real logo; brokers 2/3 fall back to the styled name.
4. **PDF pagination:** content **flows** (no fixed-height `.sheet` clipping). The running header is a
   `<table><thead>` (Chromium repeats a table-header-group reliably; `position:fixed` was not
   reliable). The cover is a separate full-bleed page before the table.
5. **Signal UI system** (`docs/v5-signal-ui-spec.md`): Inter, pine accent primaries (never ink),
   hairline borders, de-mono'd badges/tables, real shadcn components, framer-motion. Porcelana is
   deprecated.

## 7. Traps / gotchas

- **tailwind-merge + custom font sizes:** any name added to `fontSize` in `tailwind.config.ts` MUST be
  added to `FONT_SIZES` in `src/lib/utils.ts`, or that size silently vanishes wherever a colour is
  also set on the element.
- **GLM-5.3-Flash is a reasoning model:** it returns `reasoning_content` separately and leaves
  `content` empty if `max_tokens` is too small; the hardening in `ai.py` handles this — keep it.
- **Playwright pytest hygiene:** `render_expediente_html` is a pure string builder (unit-tested,
  no Chromium); `render_html_to_pdf` is stubbed in endpoint tests. Never require Chromium in the
  suite. Never touch the two AI-blanking lines in `tests/conftest.py`.
- **`document` table is the only S3-key home**; the generated PDF is a Document (category
  ANTECEDENTES_PACK) referenced by `record_expediente.pdf_document_id`.
- **No Alembic:** new columns/tables go through `scripts/migrate_case_files.py`; `create_all` covers a
  fresh local sqlite but never ALTERs an existing DB.
